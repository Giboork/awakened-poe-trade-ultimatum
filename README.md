# Awakened PoE Trade + Inscribed Ultimatum price check

Unofficial build of [Awakened PoE Trade](https://github.com/SnosMe/awakened-poe-trade) with an Inscribed Ultimatum reward-value estimate added on top of the latest official release.

## Install

1. Download the `.exe` from [Releases](../../releases/latest).
2. Close the official Awakened PoE Trade if it's running.
3. Run the `.exe`. It's portable, no installer. Windows SmartScreen will warn because it's unsigned: "More info" -> "Run anyway".

Settings are shared with the official app, so your hotkeys carry over.

## Notes

- Not affiliated with or endorsed by the Awakened PoE Trade author.
- The app will show "update available" when a new official version comes out; it won't auto-install. Grab the next build here instead.
